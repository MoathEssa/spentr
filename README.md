# Spentr

Group project repository for **SWE 463 — Mobile Application Development**, **Group 02**.
Flutter (Dart) application for Android and iOS.

Spentr is a time and earnings diary for part-time and hourly workers: one tap records a shift, and
the app turns the hours worked into money at the user's own hourly rate — offline, on the device,
with no account.
